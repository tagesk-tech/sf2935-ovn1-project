# SF2935 ÖVN1 Project

Course project for **SF2935 — Modern Methods of Statistical Learning** at KTH Royal Institute of Technology, autumn 2026.

## Status

The paper and experimental variation are currently being selected.

The project will:

1. implement the selected paper's main algorithm in Python;
2. reproduce one figure, table, or central simulation;
3. test one well-motivated variation; and
4. reproduce all reported results with one command.

## Repository structure

```text
code/       Python implementation and experiment entry point
report/     LaTeX report source and supplied NeurIPS 2026 template
results/    Generated figures and tables
slides/     Presentation source
```
